# dev-knowledge

백엔드 개발 지식을 정리하는 저장소
학습한 개념, 트러블슈팅 경험, 참고 자료 등을 마크다운으로 기록.

## 목적

- 학습한 내용을 나만의 언어로 정리하여 복습에 활용
- 실무/프로젝트에서 겪은 문제와 해결 과정 기록
- 필요할 때 빠르게 찾아볼 수 있는 개인 레퍼런스 구축

## 구조

```
dev-knowledge/
├── README.md
├── java/              # Java 언어, JVM
├── spring/            # Spring / Spring Boot
├── database/          # DB, 쿼리 최적화, 트랜잭션
├── network/           # HTTP, TCP/IP, OS 등 CS 기초
├── infra/             # Docker, CI/CD, 클라우드
└── troubleshooting/   # 문제 해결 기록
```

## 카테고리

- [Java](java/README.md) — Java 언어, JVM
- [Spring](spring/README.md) — Spring / Spring Boot
- [Database](database/README.md) — DB, 쿼리 최적화, 트랜잭션
- [Network](network/README.md) — HTTP, TCP/IP, OS 등 CS 기초
- [Infra](infra/README.md) — Docker, CI/CD, 클라우드
- [Troubleshooting](troubleshooting/README.md) — 문제 해결 기록

각 카테고리의 README.md에서 해당 주제의 개별 문서 목록을 관리.
새 문서를 추가하면 해당 카테고리 README에만 링크 추가.

## 작성 규칙

- 파일명은 주제를 알아볼 수 있도록 영문 소문자와 하이픈(`-`)으로 작성합니다.
- 문서 상단에 작성일 또는 최종 수정일을 남깁니다.
- 출처가 있는 경우 하단에 참고 링크를 남깁니다.
